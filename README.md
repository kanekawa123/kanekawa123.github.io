# Kanekawa — kanekawa.web.id

Website katalog afiliasi Shopee untuk fashion wanita: OOTD, one set Korean style,
kulot, dress kondangan, outfit hijab, dan korset pasca melahirkan.
Dikelola oleh Kanekawa — lihat juga Pinterest [@kanekawaofficial](https://id.pinterest.com/kanekawaofficial/).

Situs ini di-host dengan GitHub Pages dari repo ini (domain custom: `kanekawa.web.id`).

## Struktur repo

| Path | Isi |
| --- | --- |
| `index.html`, `koleksi.html`, `tentang.html`, `faq.html`, `kontak.html`, `kebijakan-privasi.html` | Halaman-halaman situs |
| `images/` | Foto yang dipakai langsung oleh halaman situs (dirujuk dari HTML) |
| `pins/` | Library kreatif Pinterest (`pin-*.jpg`) — tidak dirujuk HTML, dipakai sebagai sumber gambar pin |
| `logo.png`, `favicon.png`, `og-cover.jpg` | Aset brand & gambar share (Open Graph) di root |
| `sitemap.xml`, `robots.txt` | SEO — jangan dihapus |
| `google2185c4eef607cc29.html` | File verifikasi Google Search Console — **jangan dihapus**, kepemilikan Search Console bergantung pada file ini |
| `CNAME` | Domain custom GitHub Pages — **jangan dihapus/diubah** |

## Catatan perawatan

- Tambahkan foto produk baru untuk halaman ke `images/`, kreatif pin baru ke `pins/`.
- Setelah mengubah isi halaman, perbarui `<lastmod>` di `sitemap.xml`.
- Properti Search Console dimiliki akun Google `rozak0123@gmail.com` (terverifikasi 2026-11-21).
